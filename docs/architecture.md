# 系统架构说明（L0–L3 + 决策层）

> 本文依据《附1 OPEN-SZ-01 项目规划与技术验证手册》第二篇「技术方案」（第 7–9 章）整理，
> 描述端到端处理链路与各层职责边界。文中证据标签（【已验证】【待验证】【工程假设】等）沿用手册 10.1 节约定。

## 1. 端到端主链路

```
输入 → L0 输入解析与规范化 → L1 低成本取证线索 → L2 AIGC 主检测 → L3 篡改检测与定位
     → 多证据融合 → 置信度校准 → 三档决策 → 结构化报告
```

- 「多证据融合 → 置信度校准 → 三档决策 → 结构化报告」构成**决策层**。
- L1 与 L3 同时向报告输出**人类可复核的证据**，L2 提供主要的统计判别力。
- 各层均为「证据生产者」而非串行关卡；链路**可降级**，任一增强模块失效时仍能在预算内给出基于部分证据的可用结论（手册 R5 超时预案：L1 先行、L2 按最廉价成员优先、累计耗时接近上限即停止加载后续 Optional 成员）。
- 工程上划分 **MVP（承诺交付下限）** 与 **Enhanced（增量增强）** 双轨：Enhanced 模块（Effort、AEROBLADE、TruFor、视频通道）以实测增益决定去留。

## 2. 各层职责边界与预算（手册表 7-1）

| 层 | 职责（做什么） | 明确不做 | 预算目标 | 失效时的影响 |
| --- | --- | --- | --- | --- |
| **L0 输入解析与规范化** | 文件格式解析、图片/视频解码、尺寸与色彩空间统一、输入合法性检查、内容哈希、必要的 resize/crop | 不承担任何检测任务 | < 0.1 s | 无（可降级为统一处理） |
| **L1 低成本取证线索** | metadata、PNG 块序列、EXIF/XMP、JPEG 重压缩痕迹、ELA、CFA、频域特征、图像统计特征 | 不单独承担最终分类职责，不单独构成判定依据 | < 0.3 s | 损失可解释性与早退能力，不影响 L2 判别 |
| **L2 AIGC 主检测** | 多路深度检测模型的推理与打分 | 不做像素级定位 | < 1.5 s | 主要判别力下降，须依靠 L1 与决策层兜底 |
| **L3 篡改检测与定位** | 篡改检测、异常区域定位、局部异常热力图、必要的注意力可视化 | 不替代 L2 的 AIGC 判定 | < 1.0 s | 损失定位能力与部分可解释性 |
| **决策层** | 分数校准、融合、三档判定、报告生成 | 不引入新的检测模型 | < 0.1 s | 无（决定性环节） |

## 3. L1 取证线索族（手册表 8-1）

| 线索族 | 内容 | 主要用途 | 已知局限 |
| --- | --- | --- | --- |
| 容器与元数据 | PNG 块序列、EXIF/XMP、JPEG 量化表、软件指纹、隐式标识 | 报告中的离散证据；早退判据【待验证】 | 一次转存或截图即可能被抹除 |
| 压缩与重采样 | ELA 残差、JPEG ghost 双压检测、8×8 网格错位、噪声方差不一致 | 篡改辅助证据；重编码痕迹 | 对多数转码链路敏感，误报偏高 |
| 频域与上采样 | 径向功率谱峰、相邻像素关系、残差自相关周期 | 上采样指纹线索 | 与 resize、压缩强度强相关 |
| 采集指纹 | CFA 去马赛克相关性、PRNU 噪声一致性、成像流水线一致性 | 区分「相机采集」与「非采集」 | 对翻拍、强降噪、重压缩鲁棒性有限 |
| 图像统计 | 色彩统计、纹理与梯度、熵、颜色数量、通道相关性 | 输入画像；作为模型输入特征 | 场景相关性强，单独判别力有限 |

> 注意（手册 2.4/7.2）：容器指纹差异（sRGB/eXIf/IDAT 块数等）真实存在【已验证】，但反映的是两条不同的图像生产流水线而非内容真伪本身，经一次重编码、截图或转存即可能失效——因此**限定为 L1 辅助线索，不作为主判据**。L1 的「早退」能力属【工程假设】，须经消融实验确认后方可启用。

## 4. L2 AIGC 主检测：Core 与 Optional（手册 8.2）

按**信号来源差异**选择成员（而非各自报告的准确率数字）：

- **Core（必交付）**：NPR（上采样/频域残差指纹）、CLIP/AIDE 类（语义与高层表征）。
- **Optional（按实测增益取舍）**：Effort、AEROBLADE 等。
- 训练策略：**冻结骨干 + 轻量头**，不做从零训练（算力约束：消费级独显笔记本）。
- 多模型融合的价值【待验证】：互补性必须通过组合消融与错误相关性实验确认（手册 12.1），不能由模型数量推定。
- 先导基线【已验证】：47 维低层取证特征 + L2 正则逻辑回归，分层 5 折 × 5 种子，AUC ≈ 0.916、最高准确率 ≈ 85.7%（命题 119 张样本）。

## 5. L3 篡改检测与定位（手册 8.4）

三条互为校验的路径，任一失效时报告明确标注该项不可用：

1. **TruFor 异常图**（主输出）；
2. L2 分类头 patch 级聚合 + **Grad-CAM 回投**（注意：这是*关注区域解释*，与定位不同，报告中须分别标注）；
3. L1 离散线索（第三重证据）。

报告中「伪造区域标注」以 L3 定位分支输出为主，Grad-CAM 作为辅助解释单独呈现。

## 6. 视频通道（手册 8.5）

- 命题样本不含视频【已验证】，视频能力缺少本地标注数据 → 设计为**复用 L2 图像模型权重 + 时序聚合**【工程假设】，不训练独立视频模型；先简单、后复杂，有效性须在公开视频数据集上验证后方可采信。

## 7. 决策层：三档决策与结构化报告（手册第 9 章）

三档输出【工程假设】的目的不是把二分类拆成两段阈值，而是把「模型无法可靠判断」的样本**显式交给人工作业**：

| 档位 | 拟采用的判定条件（待实验确认） | 业务含义 |
| --- | --- | --- |
| 低风险 | AI 分数低于低档阈值，且未见明显异常取证证据 | 直接通过 |
| 待复核 | 模型间明显分歧；分数落入不确定区间；采集方式属已知高误报场景（手机翻拍/低照度/反光）；定位分支置信度不足 | 交人工复核——这是设计的一部分，而非系统失败 |
| 高风险 | 多个信号一致指向 AI 生成且存在相互支持的取证证据；或分数明显超过高档阈值 | 进入欺诈调查流程 |

具体阈值须在纯真实校准集上标定（误报 ≤3% 是硬护栏），并经自举（bootstrap）稳定性分析；阈值、融合权重与模型选择均在独立验证集上完成，**不使用最终测试集**。

### 结构化报告字段（手册表 9-2）

- **输入标识**：文件哈希、输入类型、分辨率/时长、L0 处理记录
- **结论**：最终结论、风险等级（低/待复核/高）、校准后置信度、校准方法与版本
- **模型证据**：各模型原始分数、融合分数、模型间分歧度、参与判定的模型清单
- **取证证据**：L1 离散线索清单（每项标注「命中/未命中/不可判」）
- **定位证据**：L3 异常图与掩膜、关键异常区域坐标、Grad-CAM（明确标注为关注区域解释）
- **不确定性**：反证说明、已知局限性（重压缩/低分辨率等困难场景）
- **可追溯性**：模型版本与权重哈希、阈值版本、推理耗时、服务版本

## 8. 关键设计约束（手册第 2–3 章）

- 【命题约束/验收标准】准确率 ≥95%、真实材料误报率 ≤3%、单份材料 ≤5s、图片+视频、覆盖 ≥3 种 AIGC 工具、伪造区域可定位、判定依据可说明；是否达成须以实测为准。
- 跨生成器泛化是核心难点：验证协议必须包含**跨生成器划分**与分层验证，不做事后补充。
- 命题样本按类别序贯排列【已验证】——任何随机切分前**必须先打乱**，否则造成严重信息泄漏。
- 「渲染 vs 拍摄」捷径偏置【已验证】：训练数据需引入拍摄态 AI 生成件与数字原生真实件，验证集按生成器与采集方式分层。
