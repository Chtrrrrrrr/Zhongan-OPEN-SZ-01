## 第 2 页｜命题解读：指标是耦合的

- **标题**：验收指标不是五个独立目标
- **要点**：
  - 五项验收标准：准确率 ≥95% ｜ FPR ≤3% ｜ 单材料 ≤5 秒 ｜ 图片+视频 & ≥3 种 AIGC 工具 ｜ 可解释性【验收标准】
  - 耦合推算：真/假 7:3 时，FPR≤3% ⇒ 真实样本最多错 0 张；Accuracy≥95% ⇒ TPR ≥ 92.9% → 主口径指标定为 **TPR@FPR=1%**
  - AI 原生度红线四要素：多模态 + 伪造痕迹检测 + 元数据分析 + ensemble（一票否决，本架构四要素齐备）
  - 判定边界：只做材料技术判定（正常/待复核/疑似），不越界做业务欺诈定性；口径对齐《人工智能生成合成内容标识办法》
- **配图占位**：`[图2-1] 指标耦合示意：Accuracy 与 FPR 联合约束 TPR 下界的三档饼图/公式条`

## 第 4 页｜数据盘查：119 张样本告诉我们什么

- **标题**：先把命题样本当"需要审计的证据"，而不是训练集
- **要点**【已验证】：
  - 构成：119 张 PNG（无视频）；AI 56 / 真实 63（47:53 ≠ 命题评测集 7:3）
  - 偏置一：标签序贯排列，跳变仅 1 次 → 划分前必须打乱（D1）
  - 偏置二：AI 类以数字渲染件为主、真实类以手机翻拍件为主 → "渲染 vs 拍摄"捷径风险 → 按采集方式分层（D3）
  - 偏置三：容器指纹系统性差异（sRGB 75% vs 38%；EXIF/XMP 0% vs 22%；IDAT>200 占 32% vs 14%）→ 只作 L1 辅助
  - 同源泄漏防护：aHash≤6 近重复 77 对、4 个混标签组 22 张 → 原子分配（D4/D5）
- **配图占位**：`[图4-1] 盘查四联图：类别构成条形 + 标签序贯跳变线 + 容器指纹对比柱 + 近重复分组示意`（数据源：`docs/data-audit.md`）

## 第 5 页｜系统架构总览

- **标题**：L0→L3 分层取证 + 决策层的可降级流水线
- **要点**：
  - 链路：L0 输入解析 → L1 低成本取证 → L2 AIGC 主检测（NPR + CLIP/AIDE）→ L3 篡改定位（TruFor）→ 融合 → 校准 → 三档决策 → 结构化报告
  - 设计原则：各层是"证据生产者"而非串行关卡；任一模块超时/异常可跳过，其余证据继续形成结论
  - 分层耗时预算：0.1 / 0.3 / 1.5 / 1.0 / 0.1 秒，总预算远小于 5 秒【命题约束】
- **配图占位**：`[图5-1] 总体技术架构图（左：图片主链路；右：视频通道与降级路径；底：决策层）`

## 第 6 页｜模型选型：少而互补

- **标题**：每一路模型都必须回答"你修正了谁的错误"
- **要点**：
  - Core：NPR（上采样伪影）+ CLIP/AIDE（语义层不自然）——信号来源正交
  - Optional：Effort（残差子空间）、AEROBLADE（免训练重建误差）——以消融决定去留
  - 定位：TruFor 输出异常图 + 置信度图；Grad-CAM 仅作关注区域解释（≠ 伪造区域）
  - 保留规则：留一法 ΔTPR@FPR=1% + 错误集合重叠度双门槛；不为模型数量付耗时
  - 明确不走：商用 API 主链路 / 多步扩散反演 / 从零训练大模型 / 生成器归因承诺
- **配图占位**：`[图6-1] 模型矩阵表 + 信号来源正交性示意（像素/语义/重建/取证四个象限）`

## 第 7 页｜双轨交付：MVP 与 Enhanced

- **标题**：任一增强模块失败，MVP 仍是完整可演示系统
- **要点**：
  - MVP（承诺下限）：L0 + L1 + L2 Core 两路 + 融合校准 + 三档报告
  - Enhanced（增量）：Effort / AEROBLADE / TruFor / Grad-CAM / 视频通道 / 鲁棒性矩阵
  - 去留判据：实测增益为准，不以模块数量论质量
  - 里程碑门禁：P0 数据基线 → P1 Core 主链路 → P2 融合阈值 → P3 视频鲁棒 → P4 冻结彩排（每阶段有 Go/No-Go 条件）

## 第 8 页｜验证方法：指标、阈值与泄漏防护

- **标题**：所有结论都必须能被复现
- **要点**：
  - 主口径 TPR@FPR=1%；辅助 Accuracy / FPR / 混淆矩阵 / ECE / P50·P95
  - 阈值标定：纯真实校准集 → 经验分位数初始估计 → bootstrap 95% 区间 → 独立真实留出集验证 → 冻结（D6）
  - 泄漏防护 D1–D8：打乱 / 生成器分层 / 采集方式分层 / 感知哈希去重 / 同源不跨集 / 测试集不调阈 / 测试集不搜权重 / 冻结后只跑一次
  - 鲁棒性矩阵：重压缩 / 缩放 / 截图 / 二次转存 / 噪声模糊 → 回答"哪条线索先失效"

## 第 11 页｜演示与落地

- **标题**：嵌入理赔流程的三档分流
- **要点**：
  - 三档输出业务含义：正常→常规通过；待复核→转人工（设计的一部分）；疑似→提交业务核查
  - 熔断原则：宁可"无法判定"转人工，不给不可信结论；一次错误"确定造假"的客诉成本 > 一次转人工
  - 工程保障：模型常驻预热 / 级联早退 / 超时降级 / 中间结果落盘可复核
  - 现场演示安排：7 分钟 7 步（盘查→L0/L1→L2 推理→三档决策→报告定位→批量评测→视频与降级）
- **配图占位**：`[图11-1] 理赔流程嵌入示意（自动通过/人工复核/欺诈调查三流向）`

## 第 12 页｜风险、边界与总结

- **标题**：我们清楚自己的能力边界
- **要点**：
  - 高危风险与预案：跨生成器掉点（多路正交 + 快速迭代路径）｜ 误报超护栏（单独校准 + 多证据一致收紧）｜ 超时（分级早退 + 熔断降级）
  - 已验证事实清单 vs 待验证清单（分两栏，诚实呈现）
  - 复现承诺：代码 + 划分冻结签名 + 权重哈希 + 阈值版本 + 预计算兜底包
  - 结束语：系统的价值不在于对每张材料都自动给出结论，而在于对可判定的样本降低成本、对不确定的样本显式暴露风险
