# 遗留问题：真实"场景照"索赔材料被系统性误判（未修复）

> 状态：**已知缺陷，未修复**。本文只记录本轮实测到的事实、边界与下一步验证顺序，
> 不提出未经验证的结论。发现于 2026-10-11 的迭代验证（`docs/iteration-2026-10-11.md`）。

---

## 1. 现象

用**冻结的部署阈值**在 41 张网络采集的真实事故/理赔照片（`testset/real/`：
车祸、水浸、火灾、财产损坏、食品变质、空白单据）上推理：

| 配置 | 被报为 `suspect`（疑似生成） | 外部融合分中位数 |
|---|---|---|
| 归档 3×3 mean/max/std（改前） | **41/41 = 100%** | 0.9664 |
| 当前 6×6 mean/max + patch（改后） | **41/41 = 100%** | 0.9705 |

同一批阈值在**命题 119 张**上的表现是正常的（FPR 3.17%）。扩大到 999 张
Synthbuster 真实照片（`real_synthbuster`，4928×3264 等大图）同样**全部**被报 `suspect`。

**这不是本轮引入的回归**：归档配置在同一批照片上也是 100%（上表第一行）。

## 2. 归因（证据）

- 全部由 `combined` 一路驱动：该路在外部真实照片上的 logits 中位数
  归档 7.95 / 当前 8.59，而部署阈值的 logit 约 0.73–1.28。
- 命题 119 张的"真实"类按手册 2.3 的盘查是"**几乎全部是手机拍摄的纸质件**，
  仅约 2 张场景照"。因此该头学到的是"**拍摄的纸**=真"，而不是"**拍摄**=真"。
  自然场景照片（无纸张纹理、无单据版式、无翻拍透视）落在其训练分布之外。
- 手册 2.4「偏置三」与 3.3「难点三」已经预警了这一失效模式：正类以数字渲染件为主、
  负类以手机拍摄件为主时，模型可能学到"渲染 vs 拍摄"这一**捷径**而非目标特征。

## 3. 为什么现有证据没有暴露它

- 命题 119 张里场景照只有约 2 张，且它们已经是全部误报预算的消耗者（seq 57/58）。
- 官方"综合准确率 ≥95%、FPR ≤3%"的验收口径**在该样本构成下可以被捷径特征满足**，
  所以指标看起来达标，而缺陷在样本构成之外才显现。

## 4. 尝试过的缓解与结果

已实现并按手册 R2 预案测了"扩充纯真实校准集"的一半（只改阈值，不重训头）：
`scripts/calibrate_with_external_reals.py`。

**机制性结论**：阈值无法分隔两个都打 0.97 的真实总体。脚本内置了可分性检查，输出
`separability.overlap`。在本次运行中，外部真实照片的 5 分位仍高于命题生成类的 5 分位，
即**两类在分数轴上重叠**——此时任何单一阈值都必须牺牲一侧。因此本缺陷**不能靠调阈值修复**，
需要的是**新的证据通道**或**训练分布修正**。

## 5. 下一步验证顺序（尚未执行）

1. **扩充负类样本再重训头**（手册 R2 的主体）：把真实场景照纳入训练负类，
   并按"拍摄态 AI 生成件"补充正类（手册 2.4 应对方式 a/b），再按同一套
   嵌套 CV 协议重测 119 张的折外指标与外部真实照的误报频率。
2. **分层校准**：按"材料形态"（单据 / 场景照）分别校准阈值（手册 3.3 建议），
   形态判别可用极低成本的特征或 CLIP 零样本分类实现。
3. **补一路与"渲染 vs 拍摄"正交的证据**：文本/版式一致性（需要 OCR）、
   屏幕翻拍摩尔纹与子像素结构、相机噪声空间相关性（PRNU 类）。
   验收判据沿用手册 12.1：新增一路必须在**低 FPR 区域**带来稳定增益，否则不进入最终版本。
4. **演示与对外表述的临时护栏**：在缺陷修复前，报告应把"场景照类材料"的结论
   统一落在**待复核**档，而不是给出高风险判定；这与手册 16.3「宁可无法判定也不给不可信判定」一致。
