⑤ 合规口径与一键复现

结论口径、证据标签约定、复现命令与接口文档入口

结论口径（术语纪律）

本系统输出的是材料层面的技术判定：normal 正常 review 待复核 suspect 疑似生成/篡改。 对 suspect 的规范表述是「疑似生成合成内容」，不构成业务欺诈定性， 最终业务结论须由人工复核与业务流程判定。

证据标签约定（《技术验证手册》表 10-1）

标签含义
【已验证】已完成，有可复现的数据或统计结果支撑
【部分验证】部分结论已验证，其余仍需补充实验
【待验证】尚无实验数据，属于需要验证的假设或候选方案
【工程假设】基于公开资料与工程经验提出的设计选择，尚未在本任务上验证
【命题约束】由命题规定的硬性要求，不是本方案的实验结果
【验收标准】判定方案是否达标的判定线，须由最终实测数据对照

逐条对照与验收清单见 docs/compliance-audit.md（合规审计报告）。

降级与错误口径

  • 输入不可解码、证据通道加载失败、单请求超时 都不是 HTTP 错误：返回 HTTP 200 + verdict=review + meta.degraded=true + uncertainty 说明（可在②中选择「1 ms 演示超时降级」）。
  • HTTP 400/403/404/405/413/415/429/500 只表示「请求本身不合法」，统一错误体为 {"error":{"code","message","details?","request_id"}}。
  • 服务默认只监听 127.0.0.1 且不含身份认证，定位为本机/内网演示与评测；对外部署须前置网关做认证与限流。
